# MetCon 40

A mobile-friendly 39-minute MetCon workout app.

## Timing

- 5-minute warm-up
- Six 4-minute EMOM rounds (A–B–A–B, 45 seconds exercise + 15 seconds transition)
- Five 1-minute recovery breaks between rounds
- 5-minute cool-down
- **Total: 39 minutes**

## Features

Fixed or random workouts, equipment selection, countdown timer, pause/resume, skip, sound cues, technique descriptions, schematic exercise illustrations and links to external video/GIF demonstrations. The app requires no dependencies or backend.

## Publish on GitHub Pages

Open Settings → Pages, set Source to **Deploy from a branch**, Branch **main**, Folder **/(root)**, then Save. After publication, visit https://ronan-brennan-ie.github.io/MetCon40/ .

Keep the page in the foreground during exercise. Mobile browsers may pause timers and audio when the phone locks. The timer compensates for elapsed time when active, but background alarms aren't guaranteed. Choose safe weights and movement ranges; stop if exercise causes pain or dizziness.
